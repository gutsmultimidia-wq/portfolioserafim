# Portfólio | Serafim Liberato

Portfólio pessoal de Serafim Liberato, estudante do curso técnico em Multimídia no CEET Vasco Coutinho.

Site feito com **HTML, CSS e JavaScript**, com visual inspirado em colagem: vermelho profundo, papel quadriculado, polaroid, tipografia gótica e dadaísta e renda floral.

## Seções

- Sobre
- Formação e cursos (com habilidades)
- Projetos
- Contato e redes

## Recursos

- Botão **MODE ON / MODE OFF** para alternar entre o visual escuro e o claro
- Layout responsivo (computador e celular)
- Fontes do Google Fonts (é preciso internet para carregá-las)

## Estrutura

```
index.html
estilo.css
script.js
imagens/
  foto.jpeg
  renda.jpg
  favicon.png
```

## Como ver

Abra o arquivo `index.html` no navegador, mantendo a pasta `imagens/` ao lado dos outros arquivos.
